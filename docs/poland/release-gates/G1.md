# Poland release gate G1 — Statutory content

**Owner:** Payroll Content + Polish payroll / tax specialist  
**Evidence tag:** `PL-GATE-G1` (a SourceArtifact reviewed by someone other than its uploader)  
**Spec rule:** NO-GO if any supported result relies on guessed or uncited content.

The gate passes only when every check below is met and the evidence is recorded. `poland_readiness.pl_readiness()` re-derives this on every request (Super Admin → Poland → Release gates, or the `readiness` block of `GET /api/payroll/poland/summary`); nothing is ticked by hand.

## Checks

- [ ] A canonical Poland pack is seeded (`pack_seeded`).
- [ ] No row carries `[PENDING G1]` (`no_pending_rows`): every PIT, ZUS, health, fund, PPK, minimum-wage, rounding and policy row has its value from an archived source reviewed by a second Super Admin. Undefined policies may be signed `NOT_SUPPORTED`, which keeps the feature blocked.
- [ ] The PIT scale rows are signed (`PL_PIT_BAND`).
- [ ] At least one official or independently prepared 2026 worked example is recorded and every expected figure matches the engine exactly (`authority_examples_match`, AC-PL-02).

## Evidence to record

The signed 2026 statutory register, the archived authority sources (S1-S12) and the worked examples with their provenance. The repository fixtures in `backend/tests/fixtures/pl_golden/` are NOT certification fixtures: they use TEST values for the points the specification leaves open.
