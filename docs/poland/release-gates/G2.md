# Poland release gate G2 — Worker coverage

**Owner:** Product + Legal / Polish payroll specialist  
**Evidence tag:** `PL-GATE-G2` (a SourceArtifact reviewed by someone other than its uploader)  
**Spec rule:** NO-GO if coverage can be inferred from a label alone.

The gate passes only when every check below is met and the evidence is recorded. `poland_readiness.pl_readiness()` re-derives this on every request (Super Admin → Poland → Release gates, or the `readiness` block of `GET /api/payroll/poland/summary`); nothing is ticked by hand.

## Checks

- [ ] The earning-class matrix is signed (`PL_EARNING_CLASS`) and complete: every component x obligation pair is present (`earning_class_matrix_complete`).
- [ ] No treatment is still `REVIEW` (`no_review_treatments`).
- [ ] The supported contract types and pay frequencies are signed (`pl_supported_contract_types`, `pl_supported_pay_frequencies`). First release: umowa o pracę on monthly pay only (decision D-2); everything else blocks with a reason code.

## Evidence to record

The employment / civil-contract coverage matrix, the ZUS title-code mapping and the demonstration that a missing fact blocks (engine tests).
