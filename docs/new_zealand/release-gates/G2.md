# New Zealand release gate G2 — Holidays and leave content (public holidays, Holidays Act values)

**Owner:** Employment / leave specialist  
**Evidence tag:** `NZ-GATE-G2` (a SourceArtifact reviewed by someone other than its uploader)

The gate passes only when every check below is met and the evidence is recorded. `nz_readiness.nz_readiness()` re-derives this on every request (Super Admin → New Zealand → Release gates, or `GET /api/payroll/new-zealand/readiness`); nothing is ticked by hand.

## Checks

- [ ] Signed national public holidays for every calendar year the pack covers (`national_public_holidays`).
- [ ] A signed anniversary day for each of the 16 regions (`regional_anniversary_days`).
- [ ] Every Holidays Act value `nz_hol_*` signed (one check per key).

## Evidence to record

The MBIE / Employment New Zealand holiday calendars used, and the reviewer's sign-off.
