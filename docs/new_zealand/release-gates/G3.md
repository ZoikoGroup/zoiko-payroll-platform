# New Zealand release gate G3 — Payday filing certified (IRD schema, deadlines, remittance dates)

**Owner:** Compliance (IRD gateway)  
**Evidence tag:** `NZ-GATE-G3` (a SourceArtifact reviewed by someone other than its uploader)

The gate passes only when every check below is met and the evidence is recorded. `nz_readiness.nz_readiness()` re-derives this on every request (Super Admin → New Zealand → Release gates, or `GET /api/payroll/new-zealand/readiness`); nothing is ticked by hand.

## Checks

- [ ] A certified payday-filing schema is installed (`export_schemas`, `new_zealand_content.NZ_EXPORT_SCHEMAS`). Until then filings are a JSON preview only and submission is refused.
- [ ] Signed: `nz_working_day_rule`, `nz_payday_filing_working_days`, `nz_paper_filing_working_days`, `nz_filing_payload_version`, `nz_large_employer_threshold`, and every remittance due-date row (`nz_remit_*`).

## Evidence to record

Inland Revenue's gateway onboarding / schema certification and the payday-filing specification version.
