# New Zealand release gate G1 — Statutory content signed (PAYE, ACC, KiwiSaver, student loan, child support)

**Owner:** Payroll / tax specialist  
**Evidence tag:** `NZ-GATE-G1` (a SourceArtifact reviewed by someone other than its uploader)

The gate passes only when every check below is met and the evidence is recorded. `nz_readiness.nz_readiness()` re-derives this on every request (Super Admin → New Zealand → Release gates, or `GET /api/payroll/new-zealand/readiness`); nothing is ticked by hand.

## Checks

- [ ] The canonical `NZ-PAYROLL-2026-27` pack is seeded (`pack_seeded`).
- [ ] No row of the pack carries `[PENDING G1]` (`no_pending_rows`).
- [ ] Every G1 authority table has signed rows: `NZ_PAYE_METHOD`, `NZ_SECONDARY_RATE`, `NZ_ND_RATE`, `NZ_IETC`, `NZ_CS_VARIATION`, `NZ_LUMP_SUM`, `NZ_HOLIDAY_ADVANCE`, `NZ_IRD_EXAMPLE` (one check per table).
- [ ] Every Inland Revenue example (`NZ_IRD_EXAMPLE`) replays through the engine and matches exactly (`ird_examples_match`) — the Super Admin "Run golden check" button shows the same result.

## Evidence to record

The archived Inland Revenue artefacts each value and table was entered from (file + SHA-256), the IRD worked examples, and the second reviewer's sign-off.
