# New Zealand release gate G4 — IRD-number security and privacy

**Owner:** Security lead  
**Evidence tag:** `NZ-GATE-G4` (a SourceArtifact reviewed by someone other than its uploader)

The gate passes only when every check below is met and the evidence is recorded. `nz_readiness.nz_readiness()` re-derives this on every request (Super Admin → New Zealand → Release gates, or `GET /api/payroll/new-zealand/readiness`); nothing is ticked by hand.

## Checks

- [ ] `NZ_IRD_KEYRING` and `NZ_IRD_FINGERPRINT_KEY` are configured (presence only — no key is ever read into a result).
- [ ] Every ACTIVE vault row is under the newest key version (`vault_on_newest_key`): run `python -m scripts.rotate_nz_ird_keys` (dry run) and `--apply` per the runbook.
- [ ] The privacy proof `tests/privacy/test_nz_ird_redaction.py` passes on the release commit (record the run as the evidence).

## Evidence to record

The Secret Manager configuration record, a rotation rehearsal's output (counts only), and the privacy test report.
