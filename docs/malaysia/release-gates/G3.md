# Malaysia release gate G3 — Authority interfaces

**Owner:** Integration + Payroll Ops  
**Evidence tag:** `MY-GATE-G3` (a SourceArtifact reviewed by someone other than its uploader)  
**Spec rule:** Filings come only from immutable payroll truth and carry their layout version (MY-021 / MY-022 / MY-028).

The gate passes only when every check below is met and the evidence is recorded. `malaysia_readiness.my_readiness()` re-derives this on every request; nothing is ticked by hand.

## Checks

- [ ] Every in-scope form has an archived authority layout in `MY_FORM_SCHEMA_CATALOG` (`form_layouts_archived`): PCB_MONTHLY (e-PCB / CP39), EPF_MONTHLY, PERKESO_EIS_MONTHLY, HRD_MONTHLY, EA, FORM_E, CP8D, CP22, CP22A, CP21.
- [ ] Due-date rows are signed: PCB remittance day, EPF / PERKESO / HRD due rules, EA and Form E, CP22 / CP22A / CP21 day counts and the clearance-hold maximum.

## Evidence to record

The archived file layouts, a test submission and receipt per authority, and the correction / rejection procedure.
