# Inbox — official Belgian source documents

**Save downloaded files here unchanged; do not rename.**

- One file per document from `../DOWNLOAD_LIST.md` (PDF, HTML saved page, XSD, XML rate file, ZIP).
- Do not edit, re-save, convert or compress a file: its SHA-256 is recorded as the evidence checksum.
- Optional: next to a file, add `<file name>.meta.txt` with three lines — `list-id: A1`, `official: yes|no`,
  `retrieved: YYYY-MM-DD` — so the parse run knows which DOWNLOAD_LIST row it answers and whether it is the
  official publication (only official publications are recorded as archived).
- Then ask for the parse run (Block F3): every file is registered with its checksum, its values are copied into the
  workbook with page / section references, and the reviewer guide is updated. Nothing is signed by the parse run.
