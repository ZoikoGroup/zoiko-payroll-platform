# Japan release gate G1 — National withholding and year-end tables signed

**Owner:** Payroll / tax lead  
**Evidence tag:** `JP-GATE-G1` (a SourceArtifact reviewed by someone other than its uploader)

The gate passes only when every check below is met in the CANONICAL Japan pack and the evidence is recorded. `japan_readiness.readiness()` re-derives this at every request; nothing is ticked by hand.

## Checks

- [ ] NTA monthly table (`JP_WHT_MONTHLY`) and bonus-rate table (`JP_WHT_BONUS`) entered from the archived NTA source and signed (no `[PENDING G1]` label).
- [ ] If the computer method is used: `JP_WHT_CMP_EID`, `JP_WHT_CMP_RATE`, `jp_wht_cmp_basic_deduction`, `jp_wht_cmp_dependant_deduction`.
- [ ] `jp_withholding_method`, `jp_wht_rounding`, `jp_wht_bonus_special_multiple` signed.
- [ ] Year-end tables `JP_YEA_EID`, `JP_YEA_BASIC`, `JP_YEA_SPOUSE`, `JP_YEA_DEPENDANT`, `JP_YEA_LIFE_INS`, `JP_YEA_RATE` and the year-end values (limit, earthquake cap, surtax, roundings, earliest month) signed.

## Evidence to record

The archived NTA artefacts (file + SHA-256) and the second reviewer's sign-off.
